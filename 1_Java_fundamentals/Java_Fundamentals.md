# Java Fundamentals

# Java Notes

### 1. Java Overview & Features

**Java** is a high-level, object-oriented, class-based programming language developed by Sun Microsystems.

Important features:

- Platform independent
- Object-oriented
- Simple
- Robust
- Secure
- Portable
- Multithreaded
- High performance using JIT
- Automatic memory management / Garbage Collection

**Interview line:**

“Java follows Write Once, Run Anywhere because Java code is compiled into platform-independent bytecode.”

---

### 2. Java Platform Independence

Java source code is compiled into **bytecode**, not directly into OS-specific machine code.

```
.java → javac → .class (Bytecode) → JVM → Machine Code
```

The same bytecode can run on Windows, Linux, or macOS using their respective JVM.

**Important:**

Java is platform independent, but **JVM is platform dependent**.

---

### 3. JDK vs JRE vs JVM

```
JDK = JRE + Development Tools
JRE = JVM + Libraries
```

- **JDK:** Used to develop + run Java programs.
- **JRE:** Used to run Java programs.
- **JVM:** Executes Java bytecode.

Examples of JDK tools:

- `javac` → compiler
- `java` → runs program
- `javadoc` → documentation

**Tricky:**

Can Java program be compiled using JRE? **No**, because `javac` is part of JDK.

---

### 4. JVM Architecture

Main components:

```
JVM
├── Class Loader
├── Runtime Data Areas
│   ├── Heap
│   ├── Stack
│   ├── Method Area
│   ├── PC Register
│   └── Native Method Stack
└── Execution Engine
    ├── Interpreter
    └── JIT Compiler
```

Important:

- **Heap:** Objects
- **Stack:** Method calls + local variables
- **Class Loader:** Loads `.class` files
- **Execution Engine:** Executes bytecode
- **JIT:** Converts frequently executed bytecode into native code

---

### 8. `main()` Method

`main()` is the **entry point** of a Java application.

```java
public static void main(String[] args)
```

- `public` → JVM can access it
- `static` → No object required
- `void` → Returns nothing
- `String[] args` → Command-line arguments

**Tricky:** Why is `main()` static?

Because JVM needs to call it **without creating an object**.

- **Static variable** → Belongs to class

### 10. Data Types

Java has **2 categories**:

#### Primitive

Store actual values.

```
byte, short, int, long
float, double
char
boolean
```

Total: **8 primitive types**

Example:

```java
int age = 22;
char grade = 'A';
```

#### Reference

Store a **reference to an object**, not the actual object itself.

Examples:

- String
- Arrays
- Classes
- Interfaces
- Objects

```java
String name = "Atharva";
```

**Important difference:**

| Primitive | Reference |
| --- | --- |
| Stores value | Stores reference |
| 8 types | No fixed number |
| `int`, `char`, `boolean` | `String`, Array, Object |

### 11. Type Casting

Converting one data type into another.

**Widening:** Smaller → larger, automatic.

```java
int a = 10;
double b = a;
```

`int → double`

**Narrowing:** Larger → smaller, manual.

```java
double a = 10.5;
int b = (int) a;
```

`double → int` → `10`

**Tricky:** Narrowing can cause data loss.

### 12. Operators

Operators are used to perform operations on values.

```java
int a = 10, b = 3;

System.out.println(a + b);        // 13  → Arithmetic
System.out.println(a > b);        // true → Relational
System.out.println(a == 10 && b == 3); // true → Logical
```

Main types:

- Arithmetic: `+ - * / %`
- Relational: `== != > < >= <=`
- Logical: `&& || !`
- Assignment: `= += -=`
- Unary: `++ --`
- Ternary: `?:`
- Bitwise: `& | ^ << >>`

### 13. Control Statements

Used to control program execution.

**if-else**

```java
int age = 20;

if (age >= 18)
    System.out.println("Adult");
else
    System.out.println("Minor");
```

**switch**

```java
int day = 1;

switch(day) {
    case 1:
        System.out.println("Monday");
        break;
    case 2:
        System.out.println("Tuesday");
        break;
}
```

**for**

```java
for(int i = 1; i <= 3; i++)
    System.out.println(i);
```

**while**

```java
int i = 1;

while(i <= 3) {
    System.out.println(i);
    i++;
}
```

**do-while**

```java
int i = 1;

do {
    System.out.println(i);
    i++;
} while(i <= 3);
```

**break**

Terminates the loop.

```java
for(int i = 1; i <= 5; i++) {
    if(i == 3)
        break;
    System.out.println(i);
}
```

Output: `1 2`

**continue**

Skips the current iteration.

```java
for(int i = 1; i <= 5; i++) {
    if(i == 3)
        continue;
    System.out.println(i);
}
```

Output: `1 2 4 5`

**Important:** `do-while` executes at least once; `while` may execute zero times.

### 14. Arrays

An array stores **multiple values of the same data type** in a fixed-size structure.

### a. 1D Array

Stores elements in a single row.

```java
int[] arr = {10, 20, 30, 40};

System.out.println(arr[0]); // 10
```

- Index starts from `0`
- Size is fixed
- `arr.length` gives size

### b. 2D Array

Array of arrays, commonly used as a matrix.

```java
int[][] matrix = {
    {1, 2},
    {3, 4}
};

System.out.println(matrix[1][0]); // 3
```

Access using:

```java
matrix[row][column]
```

### c. Multidimensional Array

Array with more than two dimensions.

```java
int[][][] arr = new int[2][3][4];
```

Used when data requires multiple dimensions.

**Important:** Java supports multidimensional arrays as **arrays of arrays**, so rows can have different lengths.

### 15. Methods

A method is a **block of code that performs a specific task**.

### 16. Method Parameters

Parameters are **values passed to a method**.

```java
void add(int a, int b) {
    System.out.println(a + b);
}

add(10, 20);
```

Here, `a` and `b` are parameters, while `10` and `20` are arguments.

---

### 17. Return Types

The return type specifies **what value a method returns**.

```java
int add(int a, int b) {
    return a + b;
}

int result = add(10, 20);
```

Here:

- `int` → return type
- `return a + b` → returned value

If a method returns nothing, use `void`.

```java
void display() {
    System.out.println("Hello");
}
```

**Important:** A method with a non-`void` return type must return a compatible value.

---

### 18. Pass-by-Value in Java

Java is **always pass-by-value**.

```java
void change(int x) {
    x = 20;
}

int a = 10;

change(a);

// a is still 10
```

For objects, Java passes a **copy of the reference**, so the object's data can be modified.

**Tricky:** Java does **not** support pass-by-reference.

**Important:** Varargs must be the **last parameter**.

### 21. `this`

`this` refers to the **current object**.

Commonly used to distinguish instance variables from parameters.

```java
class Student {
    int age;

    Student(int age) {
        this.age = age;
    }
}
```

Here, `this.age` refers to the instance variable.

### 22. `super`

`super` refers to the **immediate parent class**.

Used to access:

- Parent class variables
- Parent class methods
- Parent class constructor

```java
class Parent {
    int x = 10;
}

class Child extends Parent {
    int x = 20;

    void display() {
        System.out.println(super.x); // 10
    }
}
```

**Key difference:**

```
this  → current class/object
super → parent class
```

### 23. Access Modifiers

Access modifiers control **where a class member can be accessed**.

| Modifier | Same Class | Same Package | Subclass (other package) | Other Package |
| --- | --- | --- | --- | --- |
| `private` | Yes | No | No | No |
| `default` | Yes | Yes | No* | No |
| `protected` | Yes | Yes | Yes | No* |
| `public` | Yes | Yes | Yes | Yes |
- Protected has a special rule: an out-of-package subclass can access the protected member **through inheritance**, not through an arbitrary parent-class object.

### 1. `private`

Accessible **only inside the same class**.

```java
class Student {
    private int age = 20;

    void display() {
        System.out.println(age); // Valid
    }
}
```

```java
Student s = new Student();

// s.age; // Error
```

### 2. `default`

No keyword is used. Accessible **within the same package only**.

```java
class Student {
    int age = 20; // default
}
```

Classes in the same package can access `age`.

### 3. `protected`

Accessible:

- Same class
- Same package
- Subclasses in other packages

```java
class Parent {
    protected int age = 20;
}

class Child extends Parent {
    void display() {
        System.out.println(age); // Valid
    }
}
```

### 4. `public`

Accessible **from anywhere**.

```java
class Student {
    public int age = 20;
}
```

```java
Student s = new Student();

System.out.println(s.age); // Valid
```

### Tricky Question

**Q: Can a subclass in another package access a `protected` variable using a parent object?**

**No.**

```java
Parent p = new Parent();

// p.age; // Error
```

An out-of-package subclass can access it through **inheritance**:

```java
class Child extends Parent {
    void show() {
        System.out.println(age); // Valid
    }
}
```

**Interview rule to remember:**

```
private   → same class
default   → same package
protected → package + subclass
public    → everywhere
```

### 26. Object Creation

An object is an **instance of a class**.

Objects are commonly created using `new`.

```java
class Student {
    String name;
}

Student s = new Student();

s.name = "Atharva";
```

Here:

- `Student` → class
- `s` → reference variable
- `new Student()` → creates object
- Object is stored in **heap memory**

**Tricky:** Is `s` the object?

**No.** `s` is a **reference variable** that refers to the object.

### 27. Constructors

A constructor is a **special member of a class used to initialize an object**.

Key points:

- Same name as the class.
- Has **no return type**, not even `void`.
- Automatically called when an object is created.
- Used mainly for object initialization.
- Constructors are **not inherited**.

Example:

```java
class Student {
    String name;
    int age;

    Student(String name, int age) {
        this.name = name;
        this.age = age;
    }
}

Student s = new Student("Atharva", 22);
```

Here, `Student(...)` is the constructor and is automatically called by `new Student(...)`.

#### Types of Constructors

**1. Default constructor**

If you don't write any constructor, Java provides a **default no-argument constructor**.

```java
class Student {
    String name;
}

Student s = new Student();
```

Important: If you define any constructor yourself, Java **does not automatically provide** this constructor.

**2. No-argument constructor**

A constructor with no parameters, explicitly written by the programmer.

```java
Student() {
    name = "Unknown";
}
```

---

### 28. Constructor Overloading

Having **multiple constructors in the same class with different parameter lists**.

```java
class Student {
    String name;
    int age;

    Student() {
        name = "Unknown";
        age = 0;
    }

    Student(String name) {
        this.name = name;
    }

    Student(String name, int age) {
        this.name = name;
        this.age = age;
    }
}
```

Now we can create objects in different ways:

```java
new Student();
new Student("Atharva");
new Student("Atharva", 22);
```

This is **constructor overloading**, and it is an example of **compile-time polymorphism**.

### Tricky Questions

**Q1. Can a constructor have a return type?**

No. If you write a return type, it becomes a normal method.

```java
void Student() {
} // Method, NOT constructor
```

**Q2. Can constructors be `static`, `final`, or `abstract`?**

No. Constructors cannot be `static`, `final`, or `abstract`.

**Q3. Are constructors inherited?**

No. Constructors are **not inherited**, but a child constructor can call the parent constructor using `super()`.

**Q4. Can we overload constructors?**

Yes, by changing the **number or type/order of parameters**.

### 29. Initialization Blocks

Initialization blocks are blocks of code that execute automatically during class/object initialization.

There are two types:

### 29.1 Instance Initialization Block

Written using `{ }` without `static`.

- Executes **every time an object is created**.
- Executes **before the constructor**.

```java
class Student {

    {
        System.out.println("Instance block");
    }

    Student() {
        System.out.println("Constructor");
    }
}

Student s = new Student();
```

Output:

```
Instance block
Constructor
```

### 29.2 Static Initialization Block

Written using `static { }`.

- Executes **only once**.
- Executes when the class is **loaded/initialized**, before objects are created.
- Commonly used for static initialization.

```java
class Student {

    static {
        System.out.println("Static block");
    }

    {
        System.out.println("Instance block");
    }
}

Student s1 = new Student();
Student s2 = new Student();
```

Output:

```
Static block
Instance block
Instance block
```

**Key difference:**

```
Static block    → once per class initialization
Instance block  → once per object
Constructor     → once per object
```

**Tricky:** If a class has a static block, an instance block, and a constructor, the order is:

```
Static block → Instance block → Constructor
```

### 30. `final` Keyword

`final` is used to restrict modification.

It can be used with **variables, methods, and classes**.

**final variable:** Value cannot be reassigned.

```java
final int x = 10;

// x = 20; // Error
```

**final method:** Cannot be overridden.

```java
class Parent {
    final void show() {
        System.out.println("Hello");
    }
}
```

**final class:** Cannot be inherited.

```java
final class Parent {
}

// class Child extends Parent { } // Error
```

**Important:** A `final` reference cannot point to another object, but the object's internal data may still be modified.

### 31. Wrapper Classes

Wrapper classes provide **object versions of primitive data types**.

| Primitive | Wrapper |
| --- | --- |
| `int` | `Integer` |
| `char` | `Character` |
| `byte` | `Byte` |
| `short` | `Short` |
| `long` | `Long` |
| `float` | `Float` |
| `double` | `Double` |
| `boolean` | `Boolean` |

Example:

```java
int a = 10;
Integer b = 10;
```

**Why needed?** Collections like `ArrayList` store objects, not primitives.

```java
ArrayList<Integer> list = new ArrayList<>();
```

---

### 32. Autoboxing

Automatically converting a **primitive → wrapper object**.

```java
int x = 10;
Integer y = x;
```

Java automatically converts `int` to `Integer`.

---

### 33. Unboxing

Automatically converting a **wrapper object → primitive**.

```java
Integer x = 10;
int y = x;
```

Java automatically converts `Integer` to `int`.

**Remember:**

```
Autoboxing → primitive → wrapper
Unboxing   → wrapper → primitive
```

### 34. Enum

`enum` is used to define a **fixed set of constants**.

```java
enum Day {
    MONDAY,
    TUESDAY,
    WEDNESDAY
}

Day d = Day.MONDAY;
```

Useful when a variable should have only predefined values.

Example:

```java
enum Status {
    PENDING,
    APPROVED,
    REJECTED
}
```

**Important:** An enum is a special type of class in Java. It can have **fields, methods, and constructors**.

### 35. `Object` Class

`Object` is the **root class of Java**. Every class directly or indirectly extends `Object`.

```java
class Student {
}
```

Internally:

```
Student → Object
```

Important methods:

### 35.1 `toString()`

Returns a **string representation of an object**.

```java
Student s = new Student();

System.out.println(s.toString());
```

Usually, we **override** it to return meaningful information.

```java
@Override
public String toString() {
    return "Student";
}
```

---

### 35.2 `equals()`

Used to check **logical equality between objects**.

```java
String a = new String("Java");
String b = new String("Java");

System.out.println(a.equals(b)); // true
```

For custom classes, `equals()` should be overridden when logical equality is required.

---

### 35.3 `hashCode()`

Returns an **integer hash value** for an object.

```java
int hash = obj.hashCode();
```

Important for hash-based collections like:

```
HashMap
HashSet
```

**Important rule:**

If two objects are equal according to `equals()`, they **must have the same `hashCode()`**.

---

### 35.4 `getClass()`

Returns the **runtime class of the object**.

```java
Student s = new Student();

System.out.println(s.getClass());
```

It can be used to get class information at runtime.

---

### 35.5 `clone()`

Creates a **copy of an object**.

```java
class Student implements Cloneable {
    int age = 20;

    public Object clone() throws CloneNotSupportedException {
        return super.clone();
    }
}
```

Usage:

```java
Student s2 = (Student) s1.clone();
```

**Important:** A class generally needs to implement `Cloneable` to use `Object.clone()` successfully.

---

### Important Interview Points

```
toString() → String representation
equals()   → Logical equality
hashCode() → Hash value
getClass() → Runtime class information
clone()    → Object copy
```

**Tricky:** If `a.equals(b)` is `true`, must `a.hashCode() == b.hashCode()`?

**Yes.** But the reverse is not guaranteed: same hash code does **not** necessarily mean objects are equal.
